# 🧠 Alzheimer Detection with CNN

A deep learning project using a Convolutional Neural Network (CNN) to classify Alzheimer's disease stages from medical imaging data.

## 📘 Overview

- 🧪 Multi-class classification of Alzheimer’s disease states
- 🧠 Uses CNN architecture built in PyTorch
- 📊 Trained and evaluated within a Jupyter Notebook
- 📷 Based on medical imaging datasets

## 🛠️ Requirements

- Python 3.8+
- Jupyter Notebook
- PyTorch
- torchvision, matplotlib, numpy, etc.

Install dependencies:
```bash
pip install -r requirements.txt
```

## 🚀 Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/ExpDev-mul/Alzheimer-CNN.git
   cd Alzheimer-CNN
   ```

2. Launch the notebook:
   ```bash
   jupyter notebook Alzheimer_CNN.ipynb
   ```

3. Follow the notebook cells to train, evaluate, and visualize results.

## 📌 Notes

This project is for research and educational purposes. Data preprocessing and model tuning are simplified for demonstration. Real clinical applications require rigorous validation.
